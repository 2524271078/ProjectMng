# 交付中台 UI 风格指南

本文用于复刻当前“交付中台”的视觉语言和交互习惯，也可直接作为后续 AI 开发新系统时的 UI 约束。

## 1. 风格定位

整体属于克制、清爽、信息密度适中的企业级管理后台。视觉关键词为：浅蓝灰、轻边框、弱阴影、圆角、留白、低饱和状态色、数据优先。

界面不追求强烈装饰感。重点是让表格、筛选、表单、状态和操作层级一眼可辨。除主按钮、当前导航和少量指标卡外，大面积区域保持白色或浅蓝灰色。

## 2. 技术与组件基线

- 前端：Vue 3 + Vite。
- 组件库：Element Plus，并通过 CSS 变量统一覆盖主题。
- 图标：Element Plus Icons，使用简洁线性图标。
- 字体：`Inter, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`。
- 基础字号：14px；表格和表单内容通常为 13px。

## 3. 色彩规范

```css
:root {
  --app-canvas: #f5f8fc;       /* 页面底色 */
  --app-surface: #ffffff;      /* 卡片、面板 */
  --app-surface-muted: #eef4fa;/* 表头、次级区域 */
  --app-sidebar: #edf3fb;      /* 左侧导航 */
  --app-ink: #1e2a3e;         /* 标题、重要数字 */
  --app-text: #66758c;         /* 正文 */
  --app-subtle: #98a4b7;       /* 辅助文字 */
  --app-border: #dce6f2;       /* 常规边框 */
  --app-border-strong: #cbd9e8;/* 悬停边框 */
  --app-primary: #5b7cfa;      /* 主色 */
  --app-primary-hover: #4d70f0;
  --app-primary-soft: #e8f0ff; /* 选中背景 */
  --app-success: #34c38f;
  --app-warning: #f5b96a;
  --app-danger: #f06a6a;
  --app-info: #6fa7ff;
}
```

颜色使用规则：

- 标题和重要数字使用深蓝黑 `#1e2a3e`，正文使用蓝灰 `#66758c`，说明文字使用 `#98a4b7`。
- 主操作、选中态和链接使用柔和蓝紫 `#5b7cfa`。
- 成功、正常、在保使用绿色；预警、临期使用橙色；错误、删除、过期使用红色。
- 状态色主要用于数字、标签、小面积背景和边缘强调，不铺满大面积页面。

## 4. 页面骨架

桌面端采用左侧导航加右侧内容区：

- 左侧栏宽 212px，背景 `#edf3fb`，右侧有 1px 分隔线。
- 主内容区外边距约为上下 22px、左右 30px，最大内容宽度 1560px，水平居中。
- 顶栏高约 46px，左侧显示当前页面标题，右侧显示当前账号和退出按钮。
- 内容区尽量占满视口剩余高度；数据表格在面板内部滚动，减少整个页面上下跳动。
- 900px 以下隐藏侧栏并改为单列流式布局；树形双栏页面也改为单列。

侧栏导航项高度 40px，圆角 8px。默认文字与图标为灰蓝色；悬停时使用浅蓝底；选中时使用 `#e8f0ff` 背景、主色文字，并在左侧增加 3px 的蓝色短竖条。

## 5. 标题和内容层级

页面正文通常采用以下结构：

1. 顶栏显示模块名称，20px、半粗体。
2. 内容区标题上方可放 10px 的英文眉题，例如 `PROJECT CENTER`、`PRODUCT CATALOG`，使用主色、大写和较宽字距。
3. 页面主标题使用 24px、约 680 字重，标题下不加粗重分割线。
4. 标题右侧放搜索条件和主要操作，使用可换行的横向按钮组。

标题要短，说明文字用 12–13px 灰色。信息层级主要依靠字号、字重和留白建立，避免大量色块和粗边框。

## 6. 卡片、面板和数据概览

- 标准卡片为白底、1px 浅边框、12px 圆角，默认无阴影。
- 浮层、登录框可以使用轻阴影：`0 12px 30px rgb(50 83 122 / 8%)`。
- 指标卡最小高度约 132px，标题 12px，数字 30–32px，说明 12px。
- 指标卡允许使用很浅的蓝、橙、红背景区分语义，并在右下角增加 3px 高的小色条。
- 可点击卡片悬停时上移 1–2px，出现低透明度蓝色阴影；动画约 180ms。
- 图表保持简洁，优先使用环形图、柱状图和紧凑图例，颜色与状态色一致。

## 7. 表格与列表

- 表格是核心信息载体，字号 13px。
- 表头背景 `#eef4fa`，字号 12px、半粗体；行高紧凑但不拥挤。
- 单元格之间不显示竖线，只保留浅色横向分隔线。
- 行悬停背景使用极浅蓝 `#f5f8ff`，长文本显示省略号和悬浮提示。
- 操作列固定在右侧；“详情、编辑、服务”使用蓝色文字按钮，“删除”使用红色文字按钮。
- 高频且安全的行内操作（例如“详情”）可以做成小型浅描边按钮：高度约 26–28px，左右内边距 8–10px，圆角 6–8px，蓝色文字、极浅蓝边框或背景。它应比主按钮轻，但比纯文字链接更容易发现。
- 常用分页为 `total, sizes, prev, pager, next`，每页选项使用 10、20、50。
- 加载中使用局部 loading；无数据使用简洁空状态，不用大幅插画抢占空间。

### 可点击行的反馈

仪表盘图例、状态列表或其他整行可点击项目，应把整行做成明确的点击热区，而不是只让文字可点：

- 默认背景透明，边框也透明，保持页面安静。
- 高度约 36–42px，左右内边距 8–12px，圆角 6–8px。
- 悬停、键盘聚焦或当前选中时，显示 `#cbd9ff` 左右的浅蓝描边，并可叠加极浅蓝背景 `#f5f8ff`。
- 行内结构采用“状态圆点 + 名称 + 右对齐数量”，整行都可点击。
- 动效约 180ms，不做明显位移；选中态可以保留边框，悬停态离开后恢复。

参考样式：

```css
.clickable-row {
  display: flex;
  min-height: 40px;
  align-items: center;
  gap: 8px;
  padding: 7px 10px;
  border: 1px solid transparent;
  border-radius: 8px;
  background: transparent;
  transition: 180ms cubic-bezier(.2, .8, .2, 1);
}

.clickable-row:hover,
.clickable-row:focus-visible,
.clickable-row.is-active {
  border-color: #cbd9ff;
  background: #f5f8ff;
}

.table-detail-action {
  min-height: 28px;
  padding: 4px 9px;
  border: 1px solid #dde5fe;
  border-radius: 7px;
  background: #f8faff;
  color: #5b7cfa;
}
```

## 8. 搜索、表单和操作按钮

- 搜索条件放在页面标题右侧或表格上方，常见输入框宽约 180px，选择框宽约 140–180px。
- 按钮与控件高度通常为 34–36px，圆角 8px；登录页控件高度为 44px。
- 操作顺序通常是：筛选输入 → 搜索 → 重置 → 新增。
- 主要动作使用实心主色按钮；次要动作使用普通按钮；辅助新增可用 `primary plain`；危险操作使用 `danger plain` 或红色文字按钮。
- 输入框默认使用 1px 内描边，悬停时边框加深，聚焦时变为主色。
- 表单标签字号 13px，表单项间距约 16px。短表单用 520–620px 弹窗，复杂表单用 720–980px 弹窗或抽屉。
- 保存按钮放右侧并使用主色；取消按钮在其左侧。提交期间显示 loading，避免重复提交。

## 9. 详情、层级与反馈

- 简单详情用弹窗和 `Descriptions`；复杂对象详情用右侧抽屉，宽度约页面的 70%。
- 复杂详情按 Tab 拆分为基础信息、设备、附件、服务等区块。
- 组织、产品等层级数据使用“左侧树 + 右侧详情/表格”的双栏结构，左栏约 220–260px。
- 布尔值、状态、角色使用胶囊标签，圆角 999px；不要把普通文本全部标签化。
- 成功、警告和失败操作使用顶部轻量消息提示；删除前使用确认框。
- 所有异步列表有加载状态，失败信息尽量说明具体动作，例如“加载设备列表失败”。

## 10. 登录页

登录页仍沿用后台主色，但比业务页更轻：

- 浅蓝灰全屏背景，居中放置约 388px 宽的登录卡片。
- 卡片为半透明白色，14px 圆角，使用轻阴影和轻微背景模糊。
- 背景仅使用低透明度圆环和浅色几何图形，不使用复杂照片。
- 标题居中，26px；输入框和登录按钮高 44px。

## 11. 应保持的设计习惯

- 页面首先服务于查找、筛选、编辑和查看数据，装饰元素保持克制。
- 同一层级的间距、控件高度、按钮顺序和操作词保持一致。
- 主要内容区域尽量对齐，卡片圆角统一使用 8px 或 12px。
- 在大屏上控制内容最大宽度，避免表格无限拉伸；在小屏上允许内容自然纵向滚动。
- 权限不足的操作直接隐藏；暂不可用的上下文操作才置灰。
- 详情入口和行点击行为保持一致，行内按钮要阻止冒泡，避免误打开详情。

## 12. 不符合本系统的风格

- 高饱和渐变、霓虹色、深色赛博风。
- 大面积阴影、粗边框、超大圆角和悬浮胶囊导航。
- 营销型大标题、全屏图片、复杂动效或玻璃效果泛滥。
- 过宽留白导致数据密度过低，或把每条数据做成大卡片。
- 一个页面混用多套按钮高度、圆角或状态颜色。

## 13. 可直接交给 AI 的提示词

```text
请开发一个 Vue 3 + Vite + Element Plus 的企业级管理后台，UI 风格参考“交付中台”。

整体采用清爽、克制、信息密度适中的浅色企业后台风格。页面底色为 #f5f8fc，卡片为白色，侧栏为 #edf3fb，主色为柔和蓝紫 #5b7cfa。标题使用深蓝黑 #1e2a3e，正文使用蓝灰 #66758c，辅助文字使用 #98a4b7，边框使用 #dce6f2。成功、预警、错误分别使用 #34c38f、#f5b96a、#f06a6a。

桌面端使用 212px 左侧导航和右侧内容区，内容最大宽度 1560px。导航项高 40px、圆角 8px；当前项使用浅蓝底、主色文字和左侧 3px 蓝色标记。主内容区以白色面板、浅边框、12px 圆角为主，默认不使用明显阴影。

页面标题区使用 10px 大写英文眉题和 24px 中文主标题，右侧排列筛选、搜索、重置和新增按钮。表格字号 13px，表头浅蓝灰底，隐藏竖向边框，行悬停为极浅蓝；操作列固定右侧。高频“详情”操作优先使用高 26–28px 的小型浅蓝描边按钮，编辑可使用蓝色文字按钮，删除使用红色文字按钮。列表底部统一提供总数、每页条数和翻页。

仪表盘图例和状态列表中的每一行都应是完整点击热区，采用“状态圆点 + 名称 + 右对齐数量”的结构。默认边框透明；悬停、聚焦或选中时显示浅蓝描边 #cbd9ff 和极浅蓝背景 #f5f8ff，圆角 6–8px，高度约 36–42px，使用约 180ms 的轻量过渡。

输入框与按钮高 34–36px、圆角 8px。主操作使用实心主色按钮，次要操作使用普通按钮，危险操作使用红色描边或文字按钮。简单编辑使用 520–620px 弹窗，复杂表单使用 720–980px 弹窗，复杂详情使用约 70% 宽的右侧抽屉并通过 Tab 分组。层级数据使用左侧 220–260px 树形导航加右侧表格的布局。

所有异步区域需要 loading、空状态和明确的成功/失败消息；删除操作必须二次确认。交互动效控制在约 180ms，只允许轻微上移和低透明度阴影。900px 以下切换为单列布局并隐藏桌面侧栏。

请保持 Element Plus 的交互习惯，并通过全局 CSS 变量统一主题。避免高饱和渐变、霓虹色、厚重阴影、超大圆角、营销型大标题、复杂背景图片和无意义动画。最终界面应像成熟的内部业务系统，重点突出数据、状态和操作效率。
```
