# 服务器发布留痕

本目录用于保存每一次服务器部署、数据库迁移和紧急回滚记录。每次发布单独创建一个 `YYYY-MM-DD-简要主题.md`，从 `TEMPLATE.md` 复制并填写。

记录规则：

- 发布前先创建记录并标记为“待发布”，发布结束后补齐实际时间、命令结果和验证结论。
- 所有执行过的关键命令都要记录；命令中的密码、授权码、私钥和 Token 必须写成 `<已脱敏>`。
- 必须记录发布前、发布后 Git 提交号或交付包文件名及校验值，不能只写“最新版”。
- 数据库迁移前必须记录备份文件路径，并验证文件存在且大小非零。
- 记录 `showmigrations`、服务状态和业务冒烟测试结果。
- 失败也要留痕，包括错误摘要、处置动作和最终状态，不覆盖原记录。
- 回滚命令只在确认对应版本和备份后执行；数据库回滚不得凭空推断。
