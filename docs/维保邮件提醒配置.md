# 维保到期邮件提醒

系统将每台设备当前项目服务周期的 `service_end_date` 作为维保到期日。距离到期日 180 天以内时，设备进入“维保邮件”清单，收件人为项目负责销售在人员管理中维护的邮箱。

批量发送和自动发送会按负责销售汇总，同一销售名下本次待提醒的设备合并为一封邮件。每台设备仍保留独立发送记录；同一项目设备、同一到期日成功发送后不会被批量或自动任务重复发送，续保产生新的到期日后可以发送新一轮提醒。发送失败的记录可单独重试，已发送记录也可以在人工确认后重新发送。

## 飞书邮箱配置

在 `backend/.env` 中增加以下配置。专用密码只保存在部署机器上，不要提交到 Git：

```env
EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend
EMAIL_HOST=smtp.feishu.cn
EMAIL_PORT=465
EMAIL_HOST_USER=your-account@example.com
EMAIL_HOST_PASSWORD=your-feishu-app-password
EMAIL_USE_SSL=true
EMAIL_USE_TLS=false
DEFAULT_FROM_EMAIL=your-account@example.com
```

修改后重启 Django 服务。

## 自动发送

以下命令会扫描 180 天内到期且尚未成功发送的设备：

```powershell
cd backend
python manage.py send_service_expiry_emails
```

生产环境应使用 Windows 任务计划程序、cron 或部署平台的定时任务每天执行一次该命令。页面中的“一键发送”和单条“发送/重试”不依赖定时任务。
