# 项目设备产品型号树形选择设计

## 背景

项目中心在“新增项目设备”时，当前“产品型号”字段使用普通下拉框，直接展示全量型号列表，并将显示文本拼接为“型号名称 / 型号编码”。当型号数量增加时，定位成本高，且与项目中心“客户公司”的树形选择交互不一致。

## 目标

将项目中心“新增项目设备”中的“产品型号”输入控件调整为树形选择器，交互上与“客户公司”类似，便于按产品目录逐级定位具体型号。

## 交互设计

1. “产品型号”字段改为树形下拉选择器。
2. 树层级为：`产品线 -> 产品 -> 版本 -> 型号`。
3. 如果某个型号未绑定版本，则直接挂在所属产品节点下。
4. 只有“型号”叶子节点允许被选中，产品线、产品、版本节点仅用于展开和定位。
5. 选中后输入框中只展示“型号名称”，不再拼接“型号编码”。
6. 提交时仍然向后端传递 `device_model` 的主键 id，不修改现有接口契约。

## 数据设计

1. 复用现有接口：
   - `product-lines`
   - `products`
   - `product-versions`
   - `device-models`
2. 前端新增目录树构建函数，将四类平铺数据组装为树结构。
3. 树节点补充 `type`、`disabled`、`children`、`label` 等字段，供通用树选择器使用。

## 实现边界

1. 本次仅调整项目中心项目设备新增/编辑弹窗中的“产品型号”交互。
2. 不改动后端接口、不新增数据库字段。
3. 不调整产品中心主页面的组织树和表格行为。

## 验证要求

1. 新增树构建单测，覆盖：
   - 标准四层结构
   - 无版本型号挂载到产品节点
   - 非型号节点禁选
2. 前端构建通过。
